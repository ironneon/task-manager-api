# Task Manager API

A RESTful API built with Python, FastAPI, SQLAlchemy, and PostgreSQL.

Created by ABDMALK PH.

## Features
- Create tasks
- Get all tasks
- Update tasks
- Delete tasks
- PostgreSQL database integration
- Automatic Swagger documentation

## Technologies
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Psycopg
- Pydantic

## Installation

Clone the repository:

    git clone https://github.com/ironneon/task-manager-api.git

Install dependencies:

    pip install -r requirements.txt

Configure your PostgreSQL database in the .env file.

Run the server:

    uvicorn main:app --reload
